# Как подключить промты в Claude (облако)

1. На claude.ai создайте **Project** (например, «КБЖУ»).
2. В настройках проекта откройте **Instructions** и вставьте туда текст из `01-project-instructions.md`, затем сразу под ним — текст из `02-notion-products-db.md` и `03-medical-card.md`. В файле 01 заполните строки «Мой профиль» (цель по калориям и особенности).
3. Для базы продуктов: Settings → Connectors → подключите **Notion** и дайте доступ к страницам «Продукты (КБЖУ)» и «Медкарта».
4. Кидайте фото еды в чат проекта.
