# 🍽 Бот КБЖУ по фото (Telegram)

Присылаешь боту фото еды — он отвечает составом блюда, весом порции, калориями, белками, жирами и углеводами.
Можно добавить подпись к фото («200 г, без масла») — бот учтёт её. Есть дневник: `/today`, `/undo`.

Как работает: Telegram → бот (Python) → Claude (анализ изображения) → ответ в чат.

## Запуск: что нужно сделать тебе (≈20 минут)

### Шаг 1. Создать бота в Telegram — получить токен
1. В Telegram найди **@BotFather** и напиши `/newbot`.
2. Придумай имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456:ABC-DEF...` — сохрани его.

### Шаг 2. Получить ключ Claude API
1. Зайди на **console.anthropic.com**, зарегистрируйся, пополни баланс (хватит $5 на старте).
2. Раздел *API Keys* → *Create Key*. Сохрани ключ `sk-ant-...`.
3. Рекомендую в настройках поставить лимит трат (Billing → Limits).

### Шаг 3. Настроить `.env`
Скопируй `.env.example` в `.env` и впиши токен и ключ. Строку `ALLOWED_USER_IDS` пока оставь пустой.

### Шаг 4. Запустить
Нужен любой сервер/компьютер с **Docker** (подойдёт VPS за ~300–500 ₽/мес; бот работает без домена и открытых портов):

```bash
docker compose up -d --build
```

Посмотреть логи: `docker compose logs -f`. Остановить: `docker compose down`.

### Шаг 5. Закрыть бота от посторонних (важно!)
1. Напиши своему боту `/start` — он ответит твоим Telegram ID.
2. Впиши ID в `ALLOWED_USER_IDS` в `.env` (несколько — через запятую).
3. Перезапусти: `docker compose up -d`.

Без этого шага любой, кто найдёт бота, будет тратить твои деньги. Дополнительно стоит `DAILY_LIMIT` (фото в сутки на человека).

## Сколько это стоит
Одно фото — порядка 1–2 центов на модели по умолчанию (`claude-opus-5-5`). Чтобы удешевить в несколько раз, поставь в `.env` `CLAUDE_MODEL=claude-sonnet-5-5` (или `claude-haiku-5-5` — самая дешёвая, но менее точная).

## Для разработчика
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pytest                      # тесты (без обращения к реальному API)
python -m bot.main          # локальный запуск (нужен .env)
```
Структура: `bot/main.py` (Telegram-логика), `bot/analyzer.py` (запрос к Claude и промпт), `bot/db.py` (SQLite-дневник), `bot/formatting.py` (вид сообщений).

## Ограничения
- По фото вес определяется приблизительно — это оценка, а не медицинская рекомендация.
- Скрытые ингредиенты (масло, сахар) бот может недооценить — помогает подпись к фото.
